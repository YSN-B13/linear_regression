# 📘 Linear Regression Using Keras — Google ML Exercise

This project is a simplified implementation of Linear Regression using TensorFlow/Keras, following the structure and educational style of Google's ML curriculum. It demonstrates how a linear model can be represented, trained, and evaluated using deep learning primitives instead of traditional libraries like scikit-learn.

## 🚀 Overview

The goal of this exercise is to:

1. **Build a minimal linear regression model** using a single Keras Dense layer
2. **Train the model** using a clean, reusable experiment structure
3. **Understand the core ML workflow**:
   - Model definition
   - Compilation
   - Training
   - Metrics tracking

All code follows a well-organized, modular style used in Google's educational ML materials.
